# Backend

Серверная часть менеджера задач на Java 21 и Spring Boot

## Локальный запуск

### PostgreSQL

Для локальной разработки используются следующие значения

| Параметр | Значение |
| --- | --- |
| База данных | `task_manager` |
| Пользователь | `task_manager` |
| Пароль | `task_manager` |
| Порт | `5432` |

Это известные тестовые значения только для локальной разработки

### Приложение

Команда запускает в фоновом режиме все сервисы из `docker-compose.yml`

```bash
docker compose up -d
```

Liquibase автоматически применит миграции при запуске Spring Boot

```bash
mvn spring-boot:run
```

Пока Maven Wrapper неполный, поэтому для запуска нужен установленный Maven
После восстановления Wrapper можно использовать `./mvnw spring-boot:run`
