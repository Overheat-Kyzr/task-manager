# Task Manager

Учебный проект: менеджер задач с приоритетами, сроками выполнения и зависимостями между задачами

## Структура репозитория

- `backend/` — серверная часть на Java и Spring Boot
- `frontend/` — пользовательский веб-интерфейс
- `docs/` — архитектура, API-контракт и материалы для отчёта

## Правила работы

- Не отправлять изменения напрямую в `main`
- Работать в отдельных ветках и после проверки вливать изменения в `main`
- Одна ветка — одна задача; не смешивать в ней несвязанные изменения
- Перед началом работы обновлять локальный `main` и создавать ветку от его актуальной версии
- Не менять и не форматировать чужие файлы без необходимости
- Перед слиянием проверять свою часть: запускать относящиеся к ней тесты или описывать ручную проверку
- Не добавлять в репозиторий пароли, токены, файлы `.env`, папки сборки и настройки IDE
- Новые зависимости, изменение API и структуры базы данных сначала согласовывать с лично с Егором Дмитриевичем (ананасом)
- В описании изменений кратко указывать: что сделано, как проверить и какие ограничения остались
